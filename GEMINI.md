## Gemini CLI specifics

- This folder lives inside the Apache Airflow repository. Don't run `python`, `pytest` or `airflow` directly on the host; run the guide's tools with `uv run --project scripts python new_docs/tools/<tool>.py` from the repository root.
- Read the 3.4 source with `git show origin/v3-4-stable:<path>`.
